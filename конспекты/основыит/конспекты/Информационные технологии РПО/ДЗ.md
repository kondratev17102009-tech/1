**Задача 1**

**Количество информации в одном сообщении:** $N = 64 = 2^i \Rightarrow i = 6$ бит.
**Количество сообщений:** Файл объёмом $12\text{ байт} = 12 \times 8 = 96$ бит. Так как на одно сообщение требуется $6$ бит, получаем: $96 / 6 = 16$ сообщений.

**Задача 2**

**Информационный объём одного символа:** $N = 32 = 2^i \Rightarrow i = 5$ бит.
**Количество символов:** $100\text{ байт} = 800$ бит. Объём делим на размер одного символа: $800 / 5 = 160$ символов.

**Задача 3**

**Информационный объём одного события:** Для 2 равновероятных исходов $N = 2 \Rightarrow i = 1$ бит.
**Объём файла:** На 32 результата требуется $32 \times 1 = 32$ бита. В байтах: $32 / 8 = 4$ байта.

**Задача 4**

**Количество информации:** $i = \log_2(1 / p) = \log_2(1 / (1/16)) = \log_2(16) = 4$ бита.
**Объём файла:** На 20 попыток потребуется $20 \times 4 = 80$ бит. В байтах: $80 / 8 = 10$ байт

**Задача 5**

**Размер одного символа:** $N = 256 = 2^i \Rightarrow i = 8\text{ бит} = 1\text{ байт}$.
**Количество символов:** $2\text{ Кбайт} = 2 \times 1024 = 2048$ байт. Количество символов: $2048 / 1 = 2048$ символов.

**Задача 6**

**Размер одного сообщения:** $N = 4 = 2^i \Rightarrow i = 2$ бита.  
**Объём файла:** На 512 испытаний: $512 \times 2 = 1024$ бита. Переводим в килобайты: $1024\text{ бит} / 8 = 128\text{ байт}$; $128 / 1024 = 0,125$ Кбайт.

**Задача 7**

**Размер одного броска:** $N = 6$ граней. Так как $2^2 < 6 \le 2^3$, требуется $i = 3$ бита на результат с округлением в большую сторону.
**Объём записи:** Для 8 бросков: $8 \times 3 = 24$ бита

**Задача 8**

**Размер одного символа:** $N = 16 = 2^i \Rightarrow i = 4$ бита.
**Количество символов:** $0,5\text{ Кбайт} = 0,5 \times 1024 = 512\text{ байт} = 512 \times 8 = 4096$ бит. Количество символов: $4096 / 4 = 1024$ символа.

**Задача 9**

**Размер одной записи:** $N = 16 = 2^i \Rightarrow i = 4$ бита.
**Объём записи:** За 10 дней: $10 \times 4 = 40$ бит. В байтах: $40 / 8 = 5$ байт

**Задача 10**

**Размер одной записи:** Событие «верно/неверно» имеет 2 исхода. Минимально необходимое число бит на 1 вопрос: $i = 1$ бит.
**Объём протокола:** На 96 вопросов: $96 \times 1 = 96$ бит. В байтах: $96 / 8 = 12$ байт.

**Задача 11**

**Размер одного символа:** $N = 128 = 2^i \Rightarrow i = 7$ бит.
**Объём памяти:** На 4096 символов: $4096 \times 7 = 28672$ бита. Переводим в Кбайт: $28672 / 8 = 3584\text{ байт}$; $3584 / 1024 = 3,5$ Кбайт.

**Задача 12**

  **Размер одного сообщения:** $N = 256 = 2^i \Rightarrow i = 8\text{ бит} = 1\text{ байт}$.
**Количество извлечений:** $1\text{ Кбайт} = 1024$ байт. Количество записей: $1024 / 1 = 1024$ извлечения.
