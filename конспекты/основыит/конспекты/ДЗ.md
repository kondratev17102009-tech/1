1. **Дано:** $x = 25,0$; $x^* = 24,6$

$$\Delta = \vert{}x - x^*\vert{} = \vert{}25,0 - 24,6\vert{} = 0,4$$

$$\delta = \frac{\Delta}{\vert{}x\vert{}} = \frac{0,4}{25,0} = 0,016 \quad \text{или} \quad 1,6\%$$

$$\delta = \frac{\Delta}{\vert{}x\vert{}} = \frac{0,351}{40,054} \approx 0,008763... \approx 0,00876 \quad \text{или} \quad 0,88\%$$

5. **Дано:** $x^* = 45,678$; $\Delta_{\text{пред}} = 0,015$

По грешность $\Delta_{\text{пред}} = 0,015$ находится в разряде тысячных (третий знак после запятой). Разряд сотых (второй знак после запятой) имеет погрешность $0,015 < 0,05$ (или $0,015 \le 0,5 \cdot 0,1$).

Цифры **4, 5, 6, 7** являются верными в широком (и строгом) смысле. Сомнительной цифрой является только **8** (тысячные).

6. **Дано:** $a = 6,0 \pm 0,2$; $b = 4,0 \pm 0,1$

$$\delta_a = \frac{0,2}{6,0} \approx 0,0333 \quad (3,33\%)$$$$\delta_b = \frac{0,1}{4,0} = 0,0250 \quad (2,50\%)$$

**Сложение ($x_1 = a + b$):**

 $a + b = 6,0 + 4,0 = 10,0$
 
$\Delta_{a+b} = \Delta_a + \Delta_b = 0,2 + 0,1 = 0,3$

$\delta_{a+b} = \frac{0,3}{10,0} = 0,030 \quad (3,00\%)$

**Результат:** $a + b = 10,0 \pm 0,3 \quad (\delta = 3,00\%)$

**Вычитание ($x_2 = a - b$):**

  

$a - b = 6,0 - 4,0 = 2,0$

$\Delta_{a-b} = \Delta_a + \Delta_b = 0,2 + 0,1 = 0,3$

$\delta_{a-b} = \frac{0,3}{2,0} = 0,150 \quad (15,00\%)$

**Результат:** $a - b = 2,0 \pm 0,3 \quad (\delta = 15,00\%)$

**Сравнение и вывод:**

Относительная погрешность разности ($\delta_{a-b} = 15\%$) значительно превышает относительную погрешность суммы ($\delta_{a+b} = 3\%$).
