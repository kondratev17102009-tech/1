Множество в Python — это неупорядоченная коллекция типов данных, которая является итерируемой, изменяемой и не содержит повторяющихся элементов. Порядок элементов в множестве не определен, хотя оно может состоять из различных элементов. Главное преимущество использования множества по сравнению со списком заключается в наличии высоко оптимизированного метода проверки наличия конкретного элемента в множестве.
