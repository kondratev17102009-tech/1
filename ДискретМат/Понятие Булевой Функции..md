

**Задание 2. Доказательство законов де Моргана*

Первый закон: ¬(A ∧ B) = ¬A ∨ ¬B

| A     | B     | A ∧ B | **¬(A ∧ B)** | ¬A    | ¬B    | **¬A ∨ ¬B** |
| ----- | ----- | ----- | ------------ | ----- | ----- | ----------- |
| False | False | False | **True**     | True  | True  | **True**    |
| False | True  | False | **True**     | True  | False | **True**    |
| True  | False | False | **True**     | False | True  | **True**    |
| True  | True  | True  | **False**    | False | False | **False**   |

Вывод: Столбцы ¬(A ∧ B) и ¬A ∨ ¬B полностью совпадают, следовательно, тождество доказано.

Второй закон: ¬(A ∨ B) = ¬A ∧ ¬B

|A|B|A ∨ B|**¬(A ∨ B)**|¬A|¬B|**¬A ∧ ¬B**|
|---|---|---|---|---|---|---|
|False|False|False|**True**|True|True|**True**|
|False|True|True|**False**|True|False|**False**|
|True|False|True|**False**|False|True|**False**|
|True|True|True|**False**|False|False|**False**|

_Вывод:_ Столбцы ¬(A ∨ B) и ¬A ∧ ¬B полностью совпадают, следовательно, тождество доказано.


Задание 3. Программная задача на Python

- and вместо &&
- or вместо ||
- not вместо !

``` Python
def check_formula(a: bool, b: bool, c: bool) -> bool:
  """
   Метод принимает три логические переменные и возвращает
   результат вычисления формулы: (a && !b) || (!c && a)
   """
   # Вычисляем первую часть: (a AND NOT b)
   part1 = a and (not b)
   
   # Вычисляем вторую часть: (NOT c AND a)
   part2 = (not c) and a
   
   # Объединяем части оператором OR
   result = part1 or part2
   
   return result

# Проверка работы метода на тестовом наборе данных
test_a = True
test_b = False
test_c = True

# Вызов функции и сохранение результата
final_result = check_formula(test_a, test_b, test_c)

# Вывод результата на экран
print(f"Результат для набора ({test_a}, {test_b}, {test_c}): {final_result}")
```
