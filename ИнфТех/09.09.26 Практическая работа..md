

- **Просмотр и перемещение:** Используйте горячие клавиши для ускорения работы:
- `Ctrl + Home` - переход в самое начало документа.
- `Ctrl + End` - переход в самый конец документа.
- `Ctrl + F` - вызов панели навигации (поиск слов или заголовков).
- **Переход по закладке:**
1. Выделите нужный фрагмент текста.
2. Перейдите во вкладку **Вставка** ➔ группа «Ссылки» ➔ **Закладка**.
3. Введите имя закладки (без пробелов) и нажмите _Добавить_.
4. Для перехода нажмите `Ctrl + G` (или _Главная ➔ Найти ➔ Перейти_), выберите «Закладка» и её имя.
- **Использование гиперссылок:**
- Выделите текст ➔ нажмите `Ctrl + K` (или _Вставка ➔ Гиперссылка_).
- Можно связать текст с веб-страницей, другим файлом или _местом в этом же документе_ (например, с созданной ранее закладкой или заголовком).

- **Создание титульного листа:**
- _Вставка ➔ Страницы ➔ Титульная страница_. Выберите готовый шаблон и заполните поля (название, автор, дата).
- **Создание списка литературы:**
1. Перейдите во вкладку **Ссылки**.
2. Нажмите **Вставить ссылку** ➔ _Добавить новый источник_ (введите автора, название книги, год).
3. В конце документа нажмите **Список литературы** (Библиография) и выберите стиль оформления (например, ГОСТ или APA). Поле создастся автоматически.


- **Разрывы страниц:** Никогда не нажимайте `Enter` много раз для перехода на новую страницу! Используйте комбинацию **`Ctrl + Enter`** (_Вставка ➔ Разрыв страницы_).
- **Разрывы разделов:** Нужны, если вы хотите сделать одну страницу альбомной, а остальные оставить книжными, или изменить нумерацию.
- _Макет ➔ Разрывы ➔ Разрывы разделов (Следующая страница)_.
- **Нумерация страниц:**
- _Вставка ➔ Номер страницы_ ➔ выберите положение (сверху/снизу).
- Если на титульном листе номер не нужен: дважды кликните по номеру (откроется конструктор колонтитулов) и поставьте галочку **Особый колонтитул для первой страницы**

- **Колончатые тексты (колонки):** Выделите текст ➔ _Макет ➔ Колонки_ ➔ выберите две или три (часто применяется для газетных или журнальных статей).
- **Внесение исправлений (Рецензирование):**
- Вкладка **Рецензирование** ➔ кнопка **Исправления** (Записать исправления). Все ваши удаления и добавления текста будут подсвечиваться другим цветом.
- **Слияние документов:** Используется для массовой рассылки писем или грамот. Во вкладке _Рассылки ➔ Начать слияние_ можно связать текст документа с базой данных (например, таблицей Excel со списком имён).
- **Колонтитулы:** Повторяющийся текст вверху или внизу страницы (название работы, автор). _Вставка ➔ Верхний/Нижний колонтитул_.
- **Сноски и примечания:**
- _Сноска (внизу страницы):_ Установите курсор за словом ➔ _Ссылки ➔ Вставить сночку_.
- _Примечание (комментарий на полях):_ Выделите текст ➔ _Рецензирование ➔ Создать примечание_.

- **Создание оглавления (автоматического):**
1. Главное условие: все заголовки в тексте должны быть оформлены стилями (**Заголовок 1**, **Заголовок 2**) на вкладке _Главная_.
2. Поставьте курсор в место для оглавления.
3. Перейдите в _Ссылки ➔ Оглавление ➔ Автособираемое оглавление_.
