**Компьютерные Сети(КС)** - это система объединения компьютеры и другие устройства для обмена дынными и ресурсами. 

**Цели** - удалённый доступ к разделяемым ресурсам (получение данных  с другого устройства на расстоянии)

###### **Классификации компьютерных сетей.** 

- По среде передачи данных (проводные 
и беспроводные)

- По скорости передачи данных (низкоскоростные, среднескоростные, высокоскоростные)

- По размеру охваченной территории (глобальные, региональные, локальные)

- По организации локальной сети (одноранговые 
и с выделенным сервером)

###### **Сетевые характеристики.**

Трафик - это объём передаваемый по сети данных.
Различают два трафика:
- Входящий трафик данных получаемых компьютерам из сети.
- Исходящий трафик данных отправляемых компьютером в сеть.
(*Измеряется в байтах!*)

**Скорость передачи данных** - это фактическая скорость потока данных, прошедшего через сеть. Определяется как отношение объёма переданных данных за промежуток времени на продолжительность этого промежутка. Базовая единица - бит / сек.

![[Pasted image 20260923094442.png]]

**Пропускная способность** - максимально возможная скорость передачи данных по каналу связи. Зависящее от качества и характеристики физической среды передачи данных и используемой технологии передачи данных.

###### **Топология сети.**
**Топология сети** - это схема расположения и соединения сетевых устройств. От выбора топологии связей существенно зависят характеристики сети.

*Например, наличие между узлами нескольких путей повышает надёжность сети и делает возможным распределение загрузки между отдельными каналами.*

**Виды топологий:**
- Полно связную
- Ячеистую
- Кольцевую
- Звездообразную
- Древовидную
- Общую шину
- Смешанную
