Пошаговый алгоритм

- **Проверка условий:** Зададим отрезок ([a, b]) и малую погрешность (varepsilon ) (точность, например, (0.001)). Убедимся, что (f(a)  f(b) < 0).

- **Находим середину:** Вычислим середину отрезка (c = (a + b) / 2). 

- **Проверяем значение в середине:**
    - Если (f(c) = 0) или длина отрезка меньше погрешности ((b - a < varepsilon)), то (c) — искомый корень, поиск завершен.

- **Выбираем новый отрезок:**
    - Если (f(a) * f(c) < 0), то корень лежит в левой половине. Присвоим (b = c).
    - Иначе корень лежит в правой половине. Присвоим (a = c).

- **Повторение:** Вернемся к шагу 2, пока отрезок не станет меньше заданной точности.

Алгоритмизация для реализации.
Шаги алгоритма

- 1. **Входные данные**: отрезок ([a, b]), точность (varepsilon ) (малое число, например, `0.0001`). 

- 2. **Проверка**: убедитесь, что на концах отрезка функция имеет разные знаки: (f(a) * f(b) < 0). Если условие неверно, корня на отрезке нет или их четное число. 

- 3.**Нахождение середины**: вычисляем (c = (a + b) / 2). 

- 4.**Проверка точности**: если длина отрезка меньше погрешности ((b - a) < varepsilon) или (f(c) = 0), то (c) - искомый корень. Переходите к шагу 6.

- 5.**Выбор новой границы**:
    - Если (f(a) * f(c) < 0), то корень в левой половине: положите (b = c).
    - Иначе корень в правой половине: положите (p = c) (или (a = c)).
    - Вернитесь к шагу 3.

- 6.**Вывод**: выведите значение (c) как приближенный корень.

def bisection_method(f, a, b, eps=1e-5):
    if f(a) * f(b) >= 0:
        raise ValueError("Функция должна иметь разные знаки на концах отрезка")
    
    while (b - a) / 2 > eps:
        c = (a + b) / 2
        if f(c) == 0:
            break
        elif f(a) * f(c) < 0:
            b = c
        else:
            a = c
            
    return (a + b) / 2

# Пример использования для уравнения x^3 - x - 2 = 0 на отрезке [1, 2]
f = lambda x: x**3 - x - 2
root = bisection_method(f, 1, 2)
print(f"Корень: {root}")
