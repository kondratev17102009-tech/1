**Реляционная алгебра** - это формальный язык запросов, который работает не с числами, а с таблицами(сущностями).

**Виды операций:**

1. Теоретика множественные: Объединение. Пересечение. Разность. Декаэдров произведения.  
2. Спец. Реляционный: Выборка. Проекция. Соединение. Деление. 
3. Дополнительные: Переименование.
