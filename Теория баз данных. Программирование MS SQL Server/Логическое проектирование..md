
# Ограничения в SQL.

1. NOT NULL/NULL - Гарантирует, что в атрибуте будет или не будет значение. 
2. UNIQUE - обеспечивает уникальность значений в атрибуте или группе атрибутов.
3. PRIMARY KEY (Первичный ключ) - он однозначно идентифицирует каждую строчку таблице(Сущности). 
4. FOREIGH KEY (Внешний ключ) - он гарантирует, что значение в атрибуте внешнего ключа в одной сущности соответствует существующим значениям в первичном ключе другой сущности. Создаёт связь между двумя сущностями. 
5. CHECK - Служит для проверки значений по определенному условию. 
6. DEFAULT - Устанавливать значения по умолчяию.
